# ☕ Java: Ruta de práctica

Repositorio donde practico Java desde cero, escribiendo el código a mano, de un `System.out.println` hasta Dijkstra, AVL y árboles rojinegros. Cada ejercicio es una clase independiente y cada nivel tiene su menú en consola.

## 🗺️ Ruta

| Nivel | Tema | Estado |
|---|---|---|
| 1 | Fundamentos (imprimir, operaciones, if/else, switch, for, while) | ✅ Listo |
| 2 | Arreglos, Strings, matrices y ArrayList | 🟡 En progreso |
| 3 | Programación orientada a objetos | ⬜ Pendiente |
| 4 | Recursión, búsqueda y ordenamiento | ⬜ Pendiente |
| 5 | Listas ligadas, pilas, colas, HashMap | ⬜ Pendiente |
| 6 | Árboles, heaps y grafos | ⬜ Pendiente |
| 7 | Programación dinámica, backtracking, AVL y rojinegros | ⬜ Pendiente |
| 8 | Servicios y APIs | ⬜ Pendiente |

## 📁 Estructura

```
Java/
```

## ▶️ Cómo ejecutarlo

Necesitas JDK 17 o superior.

```bash
git clone https://github.com/Moises2136/Java.git
cd Java
javac -encoding UTF-8 Main.java
java Main
```

Reforzar lógica algorítmica y estructuras de datos para prepararme para entrevistas técnicas.
